## 1. Legacy Modules

The repository contains two Spring Boot modules under `backend/` that are not part of the active runtime architecture:
- `backend/eureka-server`: Netflix Eureka service discovery server.
- `backend/config-service`: Spring Cloud Config centralized configuration server.

### Evidence of Being Unused

1. **Only self-referenced**:
   - `backend/eureka-server`: References exist only in `backend/eureka-server/pom.xml:12, 36`, `EurekaServerApplication.java:1, 5, 8, 9, 12`, `application.properties:1, 3, 4, 5, 6`, and `EurekaServerApplicationTests.java:1, 7`.

2. **Absence from orchestration & deployment**:
   - Not present in `docker-compose.yml` or `docker-compose.debug.yml`.
   - Not present in `k8s/*.yaml` or `k8s/kustomization.yaml`.
   - Not present in CI/CD matrices (`.github/workflows/ci.yml` and `.gitlab-ci.yml` test only `api-gateway`, `queue-service`, `appointment-service`, `profile-notification-service`, and `staff-admin`).
   - Not included in any parent or aggregator Maven POM.
3. **Architectural replacement**:
   - Service routing is handled statically via Docker/Kubernetes DNS and reverse proxy routes defined in `backend/api-gateway/src/main/resources/application.properties:42-62`.

## 3. Secrets Handling & Audit

### Rules
1. **Never commit `.env`**: Always keep `.env` in `.gitignore`.
2. **Never paste secret values**: Do not share `.env` contents, API keys, or JWT secrets in team chats or issue trackers.
3. **Use placeholders in templates**: Files like `.env.example` and `k8s/secret.yaml` must contain only generic placeholders (`replace-with-...`, `REPLACE_WITH_*`).
4. **Immediate rotation**: If any credential is accidentally exposed, revoke and rotate it immediately.

### Audit Findings
- **Current state**: `.env` is untracked by Git (`git ls-files .env` returns nothing) and is ignored by `.gitignore:1`.
- **Template safety**: `.env.example` and `k8s/secret.yaml` use strictly placeholder values.
- **Git history**: verified with `git log --all --diff-filter=AMD --name-only -- .env` (no output): `.env` was never committed on any branch. An earlier automated claim that it appeared in commits a6abd8e, dacebd0 and 6ccff04 was a misreading of the log and is retracted. No credential rotation is required because of git history.
